# Where the agent container may connect (through labnet-automation-egress, CONNECT to port 443 only).
# One exact host name per line; "*.suffix" would match names under suffix (none are used here).
# Every other host is refused, and so is any of these if it resolves to a private address.
# Source: https://code.claude.com/docs/en/network-config ("Network access requirements"), checked
# 2026-10-07 for Claude Code 2.1.x. The agent container also sets CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1,
# DISABLE_AUTOUPDATER=1 and ENABLE_CLAUDEAI_MCP_SERVERS=false, so nothing else is needed.

# The Claude API itself (model requests, plus the feature flags and account profile Claude Code reads there).
api.anthropic.com

# OAuth token refresh for a saved claude.ai login: since 2.1.x the token exchange and refresh go here,
# for claude.ai accounts as well as Console ones. Without it a login stops working when its access token expires.
platform.claude.com

# claude.ai account authentication. Signing in itself happens in the `login` service, which has plain
# internet; this entry covers account lookups a headless session may make with a saved claude.ai login.
claude.ai

#   sentry.io               telemetry and error reports (off: CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC)

#                           sign-in pages in a browser, docs lookups, plugin marketplaces: not used by a run
